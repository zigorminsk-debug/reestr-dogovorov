ПОДКЛЮЧЕНИЕ ПОЛЬЗОВАТЕЛЕЙ К РЕЕСТРУ ДОГОВОРОВ

1. Установите программу на сервер под учётной записью администратора.
2. После установки в папке программы появится файл «Клиентский ярлык.url».
3. Скопируйте этот файл на рабочий стол каждого пользователя. Устанавливать
   программу и Python на рабочие места не требуется.
4. При двойном щелчке по ярлыку откроется окно браузера с общим реестром.
5. В правом верхнем углу пользователь один раз указывает своё имя. Оно будет
   записываться в историю создания и изменения договоров.

Сетевой адрес ярлыка имеет вид http://ИМЯ-СЕРВЕРА:8080/.
Если имя сервера не находится в вашей сети, замените его в файле .url на
IP-адрес сервера, например http://192.168.1.20:8080/.

На сервере входящий TCP-порт 8080 разрешается для профилей «Доменный» и
«Частный». Между рабочими местами и сервером этот порт должен быть доступен.

ОБЩАЯ БАЗА И ОБНОВЛЕНИЯ
База находится отдельно от программы:
%ProgramData%\ReestrDogovorov\data\reestr.db

При обновлении установщик заменяет только файлы программы. Каталог
%ProgramData%\ReestrDogovorov не удаляется и не перезаписывается.

Перед массовым импортом рекомендуется выбрать в левом меню «Скачать резервную
копию». Резервные копии также остаются в каталоге backups общей папки данных.

Программа предназначена для доверенной локальной сети. Не публикуйте порт 8080
напрямую в интернет без внешней системы аутентификации и HTTPS.
